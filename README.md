# Object Oriented Programming Labs

This repository contains my Object Oriented Programming (OOP) lab tasks and practice programs in C++.

## About

The programs here are written while learning the core ideas of OOP. Each lab is kept in its own folder so it is easy to find and run.

## Topics Covered

- Classes and objects
- Constructors and destructors
- Encapsulation (access specifiers, getters and setters)
- Inheritance
- Polymorphism (function overloading, operator overloading, virtual functions)
- Abstraction (abstract classes and interfaces)
- Friend functions and static members
- File handling
- Exception handling

> Update this list to match the labs you have actually completed.

Each folder contains the `.cpp` files for that lab.

## How to Compile and Run

You need a C++ compiler such as **g++** (MinGW on Windows) installed.

```bash
g++ filename.cpp -o filename
./filename
```

On Windows Command Prompt, run it with:

```bash
filename.exe
```

You can also open the files in **VS Code**, **Code::Blocks**, or **Visual Studio** and run them from there.
